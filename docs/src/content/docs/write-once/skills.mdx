title: Skills

import { Tabs, TabItem } from "@astrojs/starlight/components";

**What it is.** A folder with a `SKILL.md` (frontmatter `name` and
`description`, then the instructions) and any files it uses. The agent reads
the description, and the rest only when the skill is needed.

**Where it goes.** `.agents/skills/<name>/SKILL.md` (`~/.agents/skills` at
user scope).

```md title=".agents/skills/review/SKILL.md"
---
name: review
description: Review the change before you stop.
---
Read the diff and list problems.
```

## What each agent gets

| Agent | Gets |
| --- | --- |
| Every agent but Claude Code | nothing written: it loads `.agents/skills` where it is |
| Claude Code | a copy of each skill in `.claude/skills` |

Run `agent-harness-adapter install` after you add or change a skill, so
Claude Code's copy follows; `status` exits 1 while it is out of date.

## Limits

- Copilot, Cursor, OpenCode, Kilo Code and Devin also load `.claude/skills`, so
  with Claude Code installed they can see a skill twice. The install warns
  (`may load the skills twice`); the copies are identical.
