## Install an integration

A manifest is a file's path, a dict, or `None` for the repository's
[config](/agent-harness-adapter/reference/config/).

<Snippet code={install} region="install" lang="python" title="install.py" />

Keyword arguments take the options: `scope` (`"project"`, `"user"` or
`"local"`), `root` (the project directory), `home`, and for `install` `force`,
`True` or a list of parts. `uninstall`, `status` and `edits` take the same
arguments; `edits` returns each file you edited, with the text install would
write and the text found. Results are
the JSON of `agent-harness-adapter install --json`, as dicts.

`follow(tool, instructions, keep=…, block_order=…, scope=…, root=…, home=…)`
hands over a tool's instructions and names no agent, and returns
`{"report", "exit"}` (see
[Instructions](/agent-harness-adapter/write-once/instructions/#hand-them-over-and-name-no-harness)).

`keep_instructions(manifest, text, scope=…, root=…, home=…)` keeps a text your
tool no longer manages as the project's own (see
[Instructions](/agent-harness-adapter/write-once/instructions/#keep-a-tools-text-as-the-projects-own)),
and returns `{"report"}`, the report to print as it stands.

## Answer a hook

With `command = "mytool hook {harness} {event}"`, `run_hook` reads the
harness's input as Claude Code's and writes your answer in the harness's form.

<Snippet code={hook} region="hook" lang="python" title="hook.py" />

`parse_hook` and `answer_hook` do the two halves separately. Errors raise
`ValueError` with the library's message.
