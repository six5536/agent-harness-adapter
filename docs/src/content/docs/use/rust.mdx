## Answer a hook

The hook command reads the harness's input as a `HookInput` and answers with
an `Answer`; `emit` writes it in the harness's form.

<Snippet code={rust} region="hook" lang="rust" />

`hook::wire` gives Claude Code's input and reads Claude Code's answers, for
a command that speaks the contract itself.

## The config, from Rust

`manifest::Manifest` reads a manifest or the config
(`manifest::find_config`) and `manifest::ManifestTool` makes it a `Tool`, as
the command does.

This page's example is `crates/lib/agent-harness-adapter-core/examples/mytool.rs`;
CI builds and runs it.
