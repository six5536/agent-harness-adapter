<p class="section-label">Get started</p>
## Up and running in four steps

<Steps>

1. Install the command:

   ```sh
   npm install -g @six5536/agent-harness-adapter   # or: cargo install agent-harness-adapter
   ```

2. Run `agent-harness-adapter install` in your repository. It asks which agents you use,
   offers to move your Claude Code setup into the standard places, and writes the config,
   `.agents/agent-harness-adapter.toml`.

3. Edit `AGENTS.md` and `.agents/` from now on.

4. Run `agent-harness-adapter install` again after you add or change a skill, a subagent
   or an MCP server, or add a hook on a new event. Instructions, and hooks on events
   already in use, apply as soon as you save them.

</Steps>

<p class="section-label">Safe by default</p>
## It never takes your work

<CardGrid>
  <Card title="Your edits are kept" icon="pencil">
    A file you changed by hand is reported `edited` and left alone, unless you pass `--force`.
  </Card>
  <Card title="Uninstall is clean" icon="close">
    It takes out what it wrote and nothing else. `AGENTS.md`, `.agents/` and your own settings stay.
  </Card>
  <Card title="Hooks fail open" icon="approve-check">
    A hook that cannot start, crashes or times out allows. Your hook failing never blocks the agent.
  </Card>
  <Card title="All or nothing" icon="warning">
    An install that is refused writes nothing; every write is atomic and only on change.
  </Card>
</CardGrid>

## Ship your tool's integration

A tool declares its instructions, skills and hooks once, as a manifest or in
code; the adapter writes them into each agent's files, and its hook answers in
one format, Claude Code's.
