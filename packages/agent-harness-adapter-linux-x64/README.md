# @six5536/agent-harness-adapter-linux-x64

Prebuilt `agent-harness-adapter` binary for **linux-x64**. This is an internal artifact of
[`@six5536/agent-harness-adapter`](https://www.npmjs.com/package/@six5536/agent-harness-adapter),
which installs it automatically as an optional dependency on a matching
machine. Don't depend on it directly; install `@six5536/agent-harness-adapter`
instead.
