# @six5536/agent-harness-kit-node-win32-x64

Prebuilt Node addon of agent-harness-kit for **win32-x64**. An internal
artifact of [`@six5536/agent-harness-kit-node`](https://www.npmjs.com/package/@six5536/agent-harness-kit-node),
which installs it as an optional dependency on a matching machine. Don't
depend on it directly.
