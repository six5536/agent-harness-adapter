# @six5536/agent-harness-adapter-win32-x64

Prebuilt `agent-harness-adapter` binary for **win32-x64**. This is an internal artifact of
[`@six5536/agent-harness-adapter`](https://www.npmjs.com/package/@six5536/agent-harness-adapter),
which installs it automatically as an optional dependency on a matching
machine. Don't depend on it directly; install `@six5536/agent-harness-adapter`
instead.

## Status

**Unstable.** `agent-harness-adapter` is at a 0.x version, and its commands, options and file formats can change in any release.
