# @six5536/agent-harness-kit-linux-x64

Prebuilt `ahk` binary for **linux-x64**. This is an internal artifact of
[`@six5536/agent-harness-kit`](https://www.npmjs.com/package/@six5536/agent-harness-kit),
which installs it automatically as an optional dependency on a matching
machine. Don't depend on it directly; install `@six5536/agent-harness-kit`
instead.
